## Projeto desenvolvido para a prova de Desenvolvimento Mobile I do curso de Desenvolvimento de Software Multiplataforma (DSM) da Fatec.

## O aplicativo Média do Aluno foi feito no Android Studio, em Java, e tem duas funcionalidades:

## Calcular Média: o usuário informa as notas da Prova 1, Prova 2, Trabalho e Atividade, e o app calcula a média final. Os campos são validados para não calcular com nota em branco.

## Cadastrar Aluno: cadastro de RA, nome e e-mail, salvando os dados no banco de dados do celular. O app avisa se algum campo estiver vazio ou se o RA já estiver cadastrado, e mostra uma mensagem de sucesso ao salvar.

## Tecnologias usadas:

Android Studio
Java
ConstraintLayout
Room (persistência de dados com SQLite)
